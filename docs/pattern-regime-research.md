# A 股形态信号与市场情绪阶段实证研究（250 日全市场 Replay Audit）

> 本文档基于 AlphaSift 公开离线日线包对 **5,577 只 A 股**（扣除 60 日指标预热窗口后有效交易日 **180 天**：`2026-02-06` 至 `2026-11-09`，数据包截止 `2026-11-23`）的 `next_open` 次日开盘买入全市场回测结果编写，所有统计均遵循 **Newey-West HAC 聚类校正** 与 **Benjamini-Hochberg FDR（q ≤ 0.05）** 门槛，拒绝事后挑胜率幻觉。

## 2. 结构拆解：市场情绪周期（6 阶段）的显著尾部不对称性

180 个有效交易日按规则映射为 6 类市场情绪阶段：`分歧 (divergence)` `48d (26.67%)`、`启动 (startup)` `34d (18.89%)`、`主升 (main_up)` `32d (17.78%)`、`震荡 (neutral)` `32d (17.78%)`、`冰点 (freezing)` `21d (11.67%)`、`退潮 (ebb)` `13d (7.22%)`。

按情绪阶段切片后，我们观测到三个具有统计支撑的结构分化特征：

1. **「冰点阶段 (`freezing`)」是全形态普遍性的高危亏损源**  
   虽然冰点期仅占总交易日的 `11.67%`，却在多个形态中出现 **H1 与 H2 双半期同向负超额**：
   - `bottom_volume_yang`（底部倍量阳）在 `freezing`（`sig=88`）：日均超额 **`-3.196%`**（`nw_t=-2.53`、`ew_t=-2.46`），`H1=-4.334% (10d)`、`H2=-2.161% (11d)`；
   - `single_yang_hold`（单阳不破）在 `freezing`（`sig=553`）：日均超额 **`-2.202%`**（`ew_daily=-2.197%`, `ew_t=-3.89`），`H1=-1.434% (10d)`、`H2=-2.900% (11d)`；
   - `shooting_star_confirm`（仙人指路确认）在 `freezing`（`sig=61`）：日均超额 **`-2.741%`**，`H1=-2.947% (10d)`、`H2=-2.534% (10d)`；
   - `steady_trend_breakout`（`-1.999%`）、`box_breakout`（`-1.263%`）、`double_bottom_breakout`（`-1.060%`）、`ma20_shrink_pullback`（`-0.989%`）同样在冰点期全线负超额。  
   **量化含义**：传统“底部放量”与“单阳支撑”在冰点下跌中继中极易演变为“下跌途中的流动性诱多 / 接飞刀”。

2. **部分形态在特定结构期展现出 H1→H2 同向正超额候选**  
   - `double_bottom_breakout`（双底突破）在 `startup` 启动期（`sig=268`）：`t5_ex=+0.879%`、日均超额 **`+1.531%`**（`ew_daily=+1.399%`, `nw_t=+1.26`），且 `H1=+1.076% (15d)` 与 `H2=+1.890% (19d)` **前半与后半保持同正方向**；相比之下在 `freezing`（`-1.060%`）、`ebb`（`-1.347%`）、`main_up`（`-1.054% t5_ex`）显著拖累总账。  
   - `bottom_volume_yang` 的套牢盘压力单调递减规律显著：上方 10% 套牢盘比例 `low (<15%)` 日均超额 **`+1.033%`**（`ew_t=+1.39`, `sig=472`）→ `mid (15%-35%)` `-0.307%`（`sig=716`）→ `high (>=35%)` **`-0.961%`**（`nw_t=-2.00`, `sig=353`）。

3. **为什么不能“看全样本图表事后挑阶段”——虚假分化反例**  
   同样看分段表，`ma20_shrink_pullback` 在 `divergence` 分歧期日均 `+0.380%`、`three_white_soldiers` 在 `main_up` 主升期日均 `+0.418%`，看起来像正超额；但拆分前后半程后发现：`ma20_shrink_pullback @ divergence` 的 `H1=-1.019% (22d)` 而 `H2=+1.780% (22d)`；`three_white_soldiers @ main_up` 的 `H1=-0.992% (13d)` 而 `H2=+1.728% (14d)`。两者均为后半段反弹主导的非平稳假象。

## 3. 零前视 Walk-Forward 情绪门控审计（`H1 选阶段 → H2 样本外对比`）

为了在 **v0.4 形态激活机制** 中杜绝把“后半程行情巧合”当作真实因子，我们在 `alphasift/pattern_replay.py` 中新增了零前视 **Walk-Forward Regime Audit（`walk_forward_regime_audit`）**：

- **Strictly H1 Selection**：仅允许读取时间切片前半程（`H1`）各情绪阶段的日均超额表现（要求最少有效观察日门槛），挑选：
  1. `positive_regimes`：H1 样本内日均超额 `> 0` 的情绪阶段集合（若存在）；
  2. `non_adverse_regimes`：从全集里剔除 H1 样本内最差拖累（如 H1 日均超额 `< -0.5%` 或明显劣于同样本均值的衰退/冰点阶段）后的稳健子集；
- **Strictly OOS H2 Evaluation**：冻结 H1 选出的阶段过滤器，直接投影到从未参与选择的后半程 `H2` 上，计算：
  - `h2_baseline_daily_mean_pct`（不加任何过滤的 H2 全市场基线）；
  - `h2_positive_daily_mean_pct` 与 `delta_vs_h2_baseline_pct`；
  - `h2_non_adverse_daily_mean_pct` 与 `delta_non_adverse_vs_h2_baseline_pct`；
  - **可复现命令验证**：用户现可通过 CLI 与离线脚本直接加挂情绪白名单 / 黑名单复核净收益与 FDR 指标变化：

```bash
# 例 1：仅允许启动期运行双底突破回放
alphasift patterns replay --pattern double_bottom_breakout --allowed-regimes startup --cost-bps 25

# 例 2：全形态剔除“冰点 + 退潮”高危逆风期
alphasift patterns replay --exclude-regimes freezing,ebb --cost-bps 25
```

## 4. 下一步研究计划（v0.4 毕业路线图）

1. **延长离线包时间跨度**：继续通过 `track-record.yml` 每日增量积累，把 `H1` / `H2` 在单情绪阶段内的有效样本日从 `10~20 天` 推升至 `>= 30~50 天`，提高分层 HAC t 值检出功效；
2. **情绪 × 套牢盘联合门控**：将 `regime_stage not in {freezing, ebb}` 与 `overhead_supply_10pct < 15%` 的正交先验结合，在 `H1 -> H2` 样本外连续超越同日等权基线后再考虑进入正式 `active` 候选。
